# 虚拟显示器一键工具（直播画面中转）

把「抖音直播伴侣的画面预览」投到一块**虚拟显示器**上，再让其它直播伴侣 / OBS 采集这块虚拟屏，从而绕开摄像头、采集卡只能被一个程序独占的问题，实现多平台同时开播。

整套工具是**绿色文件夹**：自带驱动、自带 Python 运行时、无需联网、无需安装 Parsec 客户端，复制整个文件夹到另一台电脑即可用。

> **第一次使用请看同目录的 `使用手册.docx`**（图文版：三分钟快速开始、新电脑安装、控制面板详解、分辨率选择、故障排查）。本 `README.md` 保留完整技术细节与命令清单，供进阶查阅。

---

## 一、推荐入口：`0_控制面板.bat`（可视化窗口）

**新手只需要双击这一个文件。** 双击后会自动打开一个独立的图形窗口，并且**自动完成全部开启动作**（点亮虚拟屏 → 找到直播画面 → 投过去 → 持续保持），连按钮都不用点：

```
双击 0_控制面板.bat  →  （若弹 Windows 授权就点「是」）  →  面板出现，右侧能直接看到虚拟屏上的直播画面
```

面板里所有操作都是点按钮，不用记命令、不用改配置文件：

| 面板上的东西       | 作用                                                 |
| ------------ | -------------------------------------------------- |
| 顶部状态灯        | 驱动 / 保活 / 画面窗口 / 权限，一眼看出哪里不对                       |
| **一键开启直播投屏** | 全自动；再点一次就是「重新投送」，可反复用                              |
| 四个分辨率卡片      | 1080P 竖屏 / **2K 竖屏** / 1080P 横屏 / **2K 横屏**，点一下即切换 |
| 窗口下拉框 + 拾取窗口 | 选要投的窗口；「拾取」是点按钮后 8 秒内点一下那个窗口                       |
| 右侧实时预览       | 每 2 秒刷新，看到直播画面 = 采集端一定能采到                          |
| 无边框 / 开机自启开关 | 勾一下就生效                                             |
| 操作记录         | 每一步都有中文反馈，出错会直接写明原因                                |

面板只是一个只监听 `127.0.0.1` 的本地页面（用系统自带的 Edge / Chrome 以独立窗口打开），**不联网、不装任何东西**；关掉页面 2 分钟后服务自动退出，虚拟屏和保活宿主不受影响。

> 想让入口更显眼：右键 `0_控制面板.bat` → **发送到 → 桌面快捷方式**，以后从桌面双击即可。
>
> 备用：`0_MENU.bat` 是纯文字菜单，功能相同；所有旧的编号 bat 都保留，行为不变。

## 二、分辨率：竖屏与 2K

### 四档分辨率（在控制面板上点一下就切换）

| 档位        | 分辨率                  | 比例   | 驱动来源          | 首次切换    |
| --------- | -------------------- | ---- | ------------- | ------- |
| 1080P 竖屏  | 1080×1920 @ 60Hz     | 9:16 | 自定义模式（注册表槽 0） | 需一次 UAC |
| **2K 竖屏** | **1440×2560 @ 60Hz** | 9:16 | 自定义模式（注册表槽 1） | 需一次 UAC |
| 1080P 横屏  | 1920×1080 @ 60Hz     | 16:9 | 驱动内置          | 不需要     |
| **2K 横屏** | **2560×1440 @ 60Hz** | 16:9 | 驱动内置          | 不需要     |

本机实测（Parsec VDD 0.45.0.0）：

- 驱动内置 91 个模式**全是横屏**（最高 4096×2160），一个竖屏都没有；`2560×1440@60` 的 `CDS_TEST = 0`，**2K 横屏原生可用，直接切**。
- 1080×1920 和 1440×2560 默认都返回 `-2 = DISP_CHANGE_BADMODE`，但按 Parsec 官方自定义分辨率机制写入注册表并重启虚拟显卡后，**两者都实测 `CDS_TEST = 0` 并成功设置**（模式表从 91 → 92 → 93）。本机槽 0、槽 1 已写好，**以后任何档位切换都不再需要管理员**。
- `2160×3840`（4K 竖屏）不被接受，别试了。

> **2K 的取舍**：1440×2560 比 1080×1920 多 78% 像素，采集与编码更吃显卡（本机是 GT 730，长时间开播请留意掉帧）。如果抖音预览源本身只有 1080 宽，放大到 2K 不会凭空增加细节，只是边缘更平滑。
>
> 另外 Windows 会给高分屏自动套 **150% 缩放**（物理 1440×2560，桌面逻辑坐标 960×1707）。窗口投送仍会铺满整块物理屏；若采集到的画面发虚，可在「设置 → 系统 → 屏幕 → 缩放」把虚拟屏改成 100%。控制面板会把当前缩放比例直接显示出来。

### 为什么不能只改 `config.ini`

只改配置文件不会生效：驱动必须先有这个模式，Windows 才允许设置。所以竖屏档位首次使用要走一次「写注册表 + 重启显卡 + 验证」，这一步需要管理员；`core/resolutions.py` 把它做成全自动的一次 UAC，并且会**以实际设置 + 回读**为最终判据（驱动刚重启时模式表会滞后几秒，不看这一个瞬时结果）。

### 方案 A：真竖屏 1080×1920（推荐，只需授权一次）

双击 **`9_PORTRAIT.bat`**（或菜单 `[4]`），Windows 会弹一次 UAC，点「是」即可，其余全自动：

1. 按 Parsec 官方规范写入注册表自定义模式（这是唯一需要管理员的一步）：
   ```
   HKLM\SOFTWARE\Parsec\vdd\0\
       width  = 1080   (DWORD)
       height = 1920   (DWORD)
       hz     = 60     (DWORD)
   ```
2. 禁用 → 重新启用 `Parsec Virtual Display Adapter`，让驱动重新读取分辨率表（**屏幕会闪一下**，属正常）；
3. 临时点亮一块屏验证 `1080×1920@60` 确实出现在模式列表里；
4. 把 `config.ini` 改成 1080/1920；
5. 重启保活宿主、设成竖屏、回读验证。

**注册表只需写一次，之后这个模式永久存在。** 以后横竖屏切换都不再需要管理员：

| 想做的事           | 操作                            | 需要 UAC     |
| -------------- | ----------------------------- | ---------- |
| 切成竖屏 1080×1920 | `9_PORTRAIT.bat` / 菜单 `[4]`   | 首次需要，之后不需要 |
| 切回横屏 1920×1080 | `10_LANDSCAPE.bat` / 菜单 `[5]` | 不需要        |

> 驱动重启后分辨率表会有几秒延迟，脚本会自动重启宿主、重新添加虚拟屏来触发刷新，并以「实际能否设置 + 回读当前模式」作为最终判据。本机实测：注册表写好 → 显卡禁用/启用 → 宿主重启后，模式表从 91 种变成 92 种，多出的正是 `1080×1920@60`，一次 UAC 即完成，**不需要重启电脑**。极少数驱动需彻底重载时脚本会提示重启，且会把 `config.ini` 还原为横屏，避免配置与实际状态不一致。

真竖屏后，其它直播伴侣 / OBS 用「显示器采集」选 `Parsec Virtual Display Adapter`，拿到的**天然就是 9:16 画面，不用裁剪**。

### 方案 B：9:16 居中布局（完全不需要管理员）

`config.ini` 里设 `portrait_box = 1`（或菜单 `[10]` 一键切换）：

- 虚拟屏仍是 1920×1080；
- 预览窗口按 9:16 比例居中放置，实测为 **(2576, 0) 608×1080**，左右留黑；
- 采集端用「区域采集 / 裁剪」只取中间那块 608×1080，即得到 9:16。

优点：零权限、零风险、立刻生效。缺点：有效像素只有 608×1080，且采集端多一步裁剪。适合不方便弹 UAC 的电脑（如公司/网吧机器）。

### 方案 C：Windows 显示方向旋转 90°（不推荐）

在「设置 → 系统 → 屏幕 → 显示方向」里选「纵向」确实能让桌面坐标变竖，但 **DXGI / WGC 采集拿到的是旋转过的帧缓冲**，OBS 和多数直播伴侣会采集到侧倒 90° 的画面。本工具不采用这个办法。

## 三、投屏怎么做更方便

### 0. 最快的一次性办法：两个系统快捷键（零配置、零权限）

**点一下抖音直播伴侣弹出的「预览画面」窗口，然后依次按：**

| 快捷键               | 效果                       |
| ----------------- | ------------------------ |
| `Win + Shift + →` | 把这个窗口甩到右边的虚拟显示器          |
| `Win + ↑`         | 在虚拟屏上最大化，铺满 1080×1920 竖屏 |

这两个键由 Windows 窗口管理器处理，**不受 UIPI 权限限制**——即使直播伴侣以管理员运行也能用，不需要本工具、不需要 UAC。虚拟屏在左边时把 `→` 换成 `←`。

代价是纯手动：直播伴侣重开预览窗口后要再按一次，且窗口被拖走不会自动拉回。想一劳永逸地自动保持，看下面第 1、2 节和权限说明。

> 最大化后顶部会有一条标题栏，底部可能出现任务栏（如果系统设置了「在所有显示器显示任务栏」）。要纯净画面：设置 → 个性化 → 任务栏 → 关闭该选项，或在采集端裁掉边缘；也可以把 `config.ini` 的 `borderless` 设为 `1`（但窗口按钮会失效）。

### ⚠ 必读：抖音直播伴侣以管理员运行，工具必须也用管理员启动

**实测结论（本机 2026-11-06）**：抖音直播伴侣及其 `MediaSDK_Server.exe` 的「预览画面」窗口运行在 **High 完整性（管理员）** 级别。Windows UIPI 禁止普通权限进程对这类窗口调用 `SetWindowPos`，返回 `ERROR_ACCESS_DENIED (5)`。

所以**普通权限启动的宿主虽然能点亮虚拟屏，但自动投送 / 全局热键 / 拾取窗口对抖音预览窗口全部失效**（虚拟屏一直空着）。桌面 Shell 代理启动也一样，只有提权能解决。

| 想做的事              | 正确做法                                                                                          |
| ----------------- | --------------------------------------------------------------------------------------------- |
| 让工具自动投送、自动拉回、热键生效 | 双击 **`1_START_ADMIN.bat`**（或菜单 `[15]`）→ 弹一次 UAC 点「是」                                          |
| 只是临时把窗口挪过去        | 用上面第 0 节的两个快捷键，或手动拖到屏幕右边缘外                                                                    |
| 彻底免掉每次提权          | 让抖音直播伴侣**不要**以管理员身份运行（右键快捷方式 → 属性 → 兼容性 → 取消「以管理员身份运行此程序」），之后普通宿主即可全自动；但部分采集/游戏源功能可能受影响，请自行确认 |

菜单顶部新增「窗口权限」一行会自动检测并提示；`logs/host.log` 里出现「UIPI 拦截」也是同一个原因。

> 开机自启（注册表 Run）启动的是普通权限宿主，只能点亮虚拟屏、投不了管理员窗口。**每次重新登录且要自动投送抖音画面时，需要再运行一次 `1_START_ADMIN.bat`**（本机安全策略不允许创建高权限计划任务，所以无法做到完全免 UAC 的自启）。

### 1. 「拾取窗口」代替手填关键词（最省事）

以前要在 `3_LIST_WINDOWS.bat` 里找标题、手工填 `config.ini`。现在：

```
打开抖音直播伴侣 → 双击 11_PICK_WINDOW.bat（或菜单 [6]）
→ 8 秒内点一下预览窗口 / 伴侣主窗口
→ 工具自动记住这个窗口并立刻投到虚拟屏
```

记住的是**窗口句柄**（`logs/target.json`），同时把该窗口标题写进 `config.ini` 的 `title_keywords`。之后：

- 宿主每 2 秒检查一次，窗口被拖走会自动拉回虚拟屏；
- 窗口重启后 hwnd 变了也没关系：标题关键词仍会命中；
- 标题也变了（换直播间、加后缀）才回退到记住的 hwnd；
- 想换窗口：重新拾取一次；想清除：面板「清除记住的窗口」/ 菜单 `[9]` / 直接删 `logs/target.json`。

> 匹配顺序已改为**标题关键词优先、记住的 hwnd 兜底**。早期版本把 hwnd 放在最前面，实测出现过「误记住 WorkBuddy 窗口后，抖音预览画面再也投不过去」的问题，现已修复。

在可视化控制面板里，这一步更简单：点「🎯 拾取窗口」，8 秒内点一下直播画面窗口即可；也可以直接从下拉框选，右侧预览立刻能看到结果。

### 2. 全局热键

宿主运行时（菜单 `[1]` 启动后）：

| 热键               | 作用                      |
| ---------------- | ----------------------- |
| `Ctrl + Alt + V` | 把**当前活动窗口**投到虚拟屏，并自动记住它 |
| `Ctrl + Alt + B` | 把当前活动窗口送回主屏             |

用 Windows 原生 `RegisterHotKey` 实现，已实测 `WM_HOTKEY` 正常投递。临时想把浏览器、PPT、另一个预览窗口丢到虚拟屏上，按一下就行，不用碰配置、不用开菜单。不想用可在 `config.ini` 设 `hotkey = 0`。

### 3. 采集端：优先「显示器采集」

- 真竖屏（方案 A）后，显示器采集直接得到 1080×1920 的 9:16 画面，最省事；
- 「窗口采集」也能用，但窗口被遮挡 / 跨屏时容易黑帧；
- 方案 B 才需要在采集端做区域裁剪。

## 五、复制到其它电脑

1. 把整个 **`VDD-Toolkit`** 文件夹原样复制过去（U 盘 / 网盘都行，**保持目录结构完整**）。
2. **新电脑只需做一次**：右键 `5_INSTALL_DRIVER.bat` → **以管理员身份运行** → 按提示**重启电脑**。
   - 驱动是 Parsec 官方签名的 VDD 0.45（`driver/mm.inf`、`mm.dll`、`mm.cat`），不需要开启测试签名、不需要关 Secure Boot。
3. 重启后**双击 `0_控制面板.bat`**，按提示点一次 Windows 授权「是」。面板会自动点亮虚拟屏、找到画面窗口并投过去。
4. 在面板上点一下想要的分辨率卡片即可切换；**首次用竖屏档**会再弹一次 UAC 添加驱动自定义模式（一台电脑一次，之后永久生效）。
5. 如果画面窗口没自动找到：点面板「🎯 拾取窗口」，8 秒内点一下直播画面；或从下拉框直接选。
6. 想开机自动点亮虚拟屏：勾面板上的「开机自动点亮虚拟屏」（注意：自启是普通权限，只能点亮屏幕；登录后要自动投送管理员窗口，仍需双击一次 `0_控制面板.bat` 完成授权）。

**系统要求**：Windows 10 / 11 64 位。不需要装 Python、不需要装 Parsec、不需要联网。

## 六、在其它直播伴侣里采集虚拟屏

- 抖音直播伴侣 / 快手 / 视频号 / B站 等：`添加素材 / 添加画面源` → **显示器采集 / 屏幕采集 / 全屏采集** → 显示器选 **`Parsec Virtual Display Adapter`**（也可能显示为 `DISPLAY19`、`屏幕 2`）。
- OBS：`来源 +` → **显示器采集** → Display 选虚拟屏；或 `窗口采集` → 选预览窗口。

### 三个必须注意的坑

1. **必须是「扩展」模式，不能是「复制」模式。**  
   按 `Win + P` → 选 **扩展**。如果是"复制这些显示器"，虚拟屏会重复主屏内容。
2. **保持保活宿主运行。**  
   Parsec VDD 需要周期性 ping。实测在这台机器上，宿主退出后系统里**可能仍看得到这块屏**，但分辨率模式表会缩水、画面可能冻结 —— 别只凭"设置里还有第 2 块屏"判断正常。用菜单顶部或 `0_STATUS.bat` 看「保活宿主」一行。
3. **虚拟屏上的窗口不要最小化、不要被别的窗口盖住。**  
   最小化后多数采集方式拿到的是黑帧。

### 采集到黑屏 / 花屏时

- 改用「显示器采集」而不是「窗口采集」；
- 在直播伴侣设置里关闭 **硬件加速 / 显卡加速**；
- OBS 里把采集方式换成 `Windows Graphics Capture`；
- 用 `0_STATUS.bat` 确认虚拟屏还在；用 OBS 新建「显示器采集」单独预览一次；
- 刷新率保持 60Hz，**不要盲目上 120/144**（GT 730 这类老显卡带高刷虚拟屏容易异常）。

## 八、常见问题

**Q：`1_START.bat` 一闪就退，提示已有宿主在运行？**
说明虚拟屏已经开着（可能开机自启已生效）。正常的，不会重复添加屏幕。用菜单 `[1]` 可以显式重启。

**Q：填了 1080×1920 但没变竖屏？**
驱动默认不支持竖屏模式。运行 `9_PORTRAIT.bat` 点一次 UAC；或者用菜单 `[10]` 的 9:16 居中布局。详见第二节。

**Q：`9_PORTRAIT.bat` 弹 UAC 时我点了「否」会怎样？**
不会有副作用，注册表没写、配置没改，虚拟屏保持原样。随时可以重新运行。

**Q：虚拟屏亮着，但抖音预览窗口没自动过去 / 热键按了没效果？**
这是最常见的一个坑：**抖音直播伴侣以管理员权限运行**，普通权限宿主被 Windows UIPI 拦截（`SetWindowPos` 返回 `拒绝访问 5`）。看菜单顶部的「窗口权限」一行即可确认。解决办法三选一：
1. 双击 `1_START_ADMIN.bat`（或菜单 `[15]`）点一次 UAC，工具变成管理员宿主；
2. 点一下预览窗口，按 `Win + Shift + →` 再按 `Win + ↑`（完全不需要权限）；
3. 让直播伴侣不要以管理员运行（右键快捷方式 → 属性 → 兼容性 → 取消勾选）。

另外注意窗口标题是「**预览画面**」不是「画面预览」，词序写反会导致关键词匹配不到 —— `config.ini` 里已经改成正确值，也可以用 `11_PICK_WINDOW.bat` 按句柄拾取，彻底不受标题影响。

**Q：热键没反应？**
先确认上一问的 UIPI 问题。再看宿主是否在运行（菜单顶部「保活宿主」）；`Ctrl+Alt+V` 可能被别的软件占用，查 `logs/host.log` 里有没有「全局热键已注册」。备用方案：`11_PICK_WINDOW.bat` 或菜单 `[7]`。

**Q：提示驱动没装 / `DRIVER_MISSING`？**
右键管理员运行 `5_INSTALL_DRIVER.bat`，**重启**后再试。

**Q：装了驱动还是不行？**
设备管理器 → 显示适配器里看 `Parsec Virtual Display Adapter` 有没有黄色感叹号；有则右键卸载设备后重跑安装脚本并重启。

**Q：会不会和向日葵 / GameViewer 的虚拟显卡冲突？**
不会。本机同时有 `OrayIddDriver`、`GameViewer Virtual Display Adapter` 和 `Parsec Virtual Display Adapter`，本工具只操作 Parsec 那一块，实测共存正常。

**Q：能加多块虚拟屏吗？**
驱动最多支持 8 块，目前工具只点亮 1 块（直播场景够用）。

**Q：会修改系统设置吗？**
只做四件事：安装/卸载虚拟显卡驱动、添加/移除虚拟显示器、移动指定窗口、以及（切竖屏时）写入 Parsec 官方规定的自定义分辨率注册表项并重启该虚拟显卡。不改主屏分辨率。卸载驱动用 `6_UNINSTALL_DRIVER.bat`；想删掉自定义分辨率，删 `HKLM\SOFTWARE\Parsec\vdd\0` 子键即可。

## 九、放到 GitHub / 二次开发

### 目录里有什么

| 目录 | 内容 | 是否进 Git |
|---|---|---|
| `core/` | 全部源码（纯 Python 标准库，无第三方依赖） | ✅ 进 |
| `*.bat` | 15 个中文入口脚本（纯 ASCII，兼容 GBK 控制台） | ✅ 进 |
| `driver/` | Parsec VDD 0.45 官方签名驱动 + `nefconw.exe` 安装器 | ⚠️ 见下方说明 |
| `runtime/` | 便携 Python 3.12.10（22 MB，含官方 DLL） | ⚠️ 见下方说明 |
| `logs/` | 运行日志与本机状态 | ❌ 已由 `.gitignore` 排除 |
| `core/assets/` | 品牌 logo 与窗口图标 | ✅ 进 |

`.gitignore` 已经配好：`logs/` 里的运行痕迹、`__pycache__`、`.pyc`、编辑器配置、临时压缩包都不会被提交。

### 关于 `driver/` 和 `runtime/` 的取舍

这两个目录都是**第三方二进制**，不是本工具的代码：

- **`driver/`** 是 Parsec 官方签名的 VDD 驱动文件（Parsec VDD 0.45.0.0），版权归 Parsec。参考项目 [nomi-san/parsec-vdd](https://github.com/nomi-san/parsec-vdd) 把驱动放在自己的 Releases 里分发，本仓库若公开，建议照此办理 —— 放在 **Releases 附件**，仓库里只保留 `5_INSTALL_DRIVER.bat` 的安装逻辑并注明下载地址。
- **`runtime/`** 是 Python 官方的 embeddable 发行包（PSF 许可，可自由再分发），但会让仓库体积增加约 22 MB。

**三种上传方案，按需要选一个：**

| 方案 | 做法 | 适合 |
|---|---|---|
| A. 完整可跑（推荐给自用/小范围） | `driver/`、`runtime/` 一起提交 | 别人 clone 下来双击就能用，仓库约 23 MB |
| B. 纯净源码 | 把 `.gitignore` 里 `runtime/` `driver/` 两行的注释去掉 | 仓库只有源码（< 1 MB），使用者自行补齐依赖 |
| C. 混合 | `runtime/` 进仓库，`driver/` 走 Releases 附件 | 兼顾体积与合规，clone 后只需补驱动 |

方案 B / C 的使用者，缺 `runtime/` 时需要一个 `runtime/python.exe`；缺 `driver/` 时按 Parsec 官方说明安装 VDD 0.45 即可，`5_INSTALL_DRIVER.bat` 里的三条 `nefconw` 命令可以直接复用。

